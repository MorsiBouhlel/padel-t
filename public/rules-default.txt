Le tournoi se déroule en deux phases :
- Une phase de championnat, disputée selon un système de points.
- Une phase finale : les 4 premières paires disputent les play-offs (demi-finales, finale et match de classement).

Report d'un match
En cas d'accord entre les deux paires : convenir d'une nouvelle date, réserver le terrain, jouer avant la journée suivante et communiquer la date et le résultat dans le groupe WhatsApp. Si le match n'est pas joué avant la journée suivante, les deux paires sont déclarées perdantes sur le score de 6-0 / 6-0.

Match non joué
Tout match non disputé à la date prévue entraîne une défaite 6-0 / 6-0 pour la paire concernée.

Format des matchs et points
- Meilleur des trois sets ; à un set partout, un troisième set complet est disputé (pas de super tie-break).
- À 40-40, point décisif (pas d'avantage).
- Match gagné : 3 points. Match perdu : 0 point.
- Départage : points, différence de score, score pour, confrontation directe, matchs joués (croissant), puis tirage au sort.

Changement de partenaire
Autorisé uniquement en cas de force majeure et pendant le championnat. Pénalité de 2 points si le changement a lieu à partir des trois premières journées. Aucun changement pendant les phases finales.
